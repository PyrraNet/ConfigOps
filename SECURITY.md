# Security policy

ConfigOps records configuration evidence and can write previous values back to WordPress. Security reports deserve a private channel.

## Supported version

Only the newest published release is supported during the `0.x` technical-preview phase.

## Reporting a vulnerability

Please email [felix@pyrra.net](mailto:felix@pyrra.net) with the affected ConfigOps version and a minimal reproduction. Do not include credentials, production option values, database exports, or customer data in a public issue.

pyrra will acknowledge a report as soon as practical, validate the affected version, and coordinate disclosure after a fix is available. Reports that demonstrate secret exposure, authorization bypass, unsafe restore, or stored cross-site scripting receive priority.
