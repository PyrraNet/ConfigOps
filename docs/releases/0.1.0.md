# ConfigOps 0.1.0

**Released:** 2026-08-12<br>
**Theme:** recorder first

The first technical preview introduced explicit local capture sessions, request grouping, typed nested diffs, secret redaction before persistence, conservative noise separation, and conflict-checked compensating undo.

It shipped exact WordPress Core 7.0, WP Mail SMTP Free 4.9.0, and Yoast SEO Free 28.2 contracts; bounded local media/content references; value-free unmanaged-write warnings; local retention and privacy disclosure; and a code-split WordPress-native review interface.

## Original runtime contract

- WordPress 7.0 or newer
- PHP 8.3–8.5
- Single-site WordPress
- Options API configuration only

Version 0.2.0 supersedes this runtime contract with PHP 8.2 support and substantially stronger release evidence. The recorder remains a technical preview rather than a backup or deployment system.
