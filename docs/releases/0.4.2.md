# ConfigOps 0.4.2

Released 2026-08-19. This patch adds a public, disposable live demo that proves the ConfigOps trust path before installation.

## What changed

- The WordPress.org Blueprint installs and activates ConfigOps and WP Mail SMTP Free 4.9.0, signs in, and opens the sender settings directly.
- A small instruction asks the visitor to change only the sender email and save.
- The prepared baseline removes setup noise, so the Evidence Card and Review show exactly that one setting.
- The visitor can undo the change through ConfigOps and verify the original sender email is restored.
- CI now repeats this complete browser flow against a fresh Playground instance.

## Try it

[Open the ConfigOps live demo](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fplugins.svn.wordpress.org%2Fconfigops%2Fassets%2Fblueprints%2Fblueprint.json)

The preview runs in a disposable browser environment. It does not connect to or change an existing WordPress website.

## Runtime contract

There are no production runtime changes from 0.4.1. The single-site and Multisite observation, Network Admin evidence, guarded undo, compatibility, privacy, and storage contracts remain unchanged.

## Release evidence

- Official Playground Blueprint schema validation and WordPress.org's 100 KiB asset boundary.
- Fresh-install browser verification of direct landing, save, Evidence Card, one-field Review, guarded Undo, and restored baseline.
- Deterministic release archive, synchronized version metadata, official WordPress Plugin Check, and the complete ConfigOps test suite.
