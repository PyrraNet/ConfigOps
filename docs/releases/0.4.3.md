# ConfigOps 0.4.3

Released 2026-08-19. This patch verifies and enables the ConfigOps WordPress Core contract for WordPress 7.1.

## What changed

- The WordPress Core adapter now accepts final WordPress 7.0 and 7.1 versions and continues to fail closed for untested WordPress 7.2 releases.
- CI exercises the complete PHP behavior suite on the official WordPress 7.1 RC4 package at both ends of the supported PHP range.
- The exact WP Mail SMTP 4.9.0 and Yoast SEO 28.2 contracts, their real browser save/review/undo flows, and native MySQL and MariaDB lanes also run on WordPress 7.1 RC4.
- WordPress.org and project documentation now advertise WordPress 7.1 as the tested ceiling.

## Runtime contract

ConfigOps supports WordPress 7.0–7.1 and PHP 8.2–8.5. Single-site evidence, network-active Multisite isolation, Network Admin evidence, guarded undo, privacy, and storage boundaries are unchanged.

## Release evidence

- Official WordPress 7.1 RC4 package plus an explicit final-7.1 adapter-boundary regression check.
- Parser, unit, hostile-input, single-site integration, Multisite lifecycle, exact-adapter, and browser workflow contracts.
- Native MySQL 8.4 and MariaDB 11.4 lanes, deterministic packaging, and WordPress Plugin Check.
