# ConfigOps 0.2.0

**Released:** 2026-08-13<br>
**Theme:** trust and compatibility

## Highlights

- Expanded the supported runtime to PHP 8.2–8.5, with a lifecycle guard for the minimum branch.
- Added exact WP Mail SMTP Free 4.9.0 and Yoast SEO Free 28.2 integration and browser-flow evidence on PHP 8.2 and 8.5.
- Enforced 70% tracked-production and 75% trust-boundary line-coverage floors.
- Added hostile-input contracts for malformed intent evidence, oversized/deep values, forged redaction nodes, secret variants, serialization-like payloads, and pointer collisions.
- Turned product warnings, notices, and deprecations into test failures.
- Locked compatibility tooling and added Composer/npm vulnerability audits.
- Made release archives byte-reproducible before WordPress Plugin Check.
- Added this versioned VitePress operations and safety manual with GitHub Pages deployment.

## Verified release-candidate evidence

- WordPress 7.0 and latest
- PHP 8.2, 8.3, 8.4, and 8.5
- MySQL 8.4 and MariaDB 11.4
- WP Mail SMTP Free 4.9.0 and Yoast SEO Free 28.2
- 77.30% tracked-production line coverage
- 79.02% trust-boundary line coverage

## Boundaries

PHP 8.1 and older remain unsupported because they are outside upstream security support. Coverage is a release signal, not proof of defect absence. This release remains a local, single-site Options API recorder; fleet management and generic custom-table rollback are not included.

See the repository `CHANGELOG.md` for the canonical chronological record.
