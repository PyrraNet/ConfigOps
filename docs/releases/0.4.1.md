# ConfigOps 0.4.1

Released 2026-08-19. This patch makes the ConfigOps website and documentation directly visible near the top of the WordPress.org plugin description.

## What changed

- The public listing now links to [configops.pyrra.net](https://configops.pyrra.net/).
- The public listing links directly to the [ConfigOps documentation](https://configops.pyrra.net/docs/).
- Plugin homepage metadata continues to identify the dedicated ConfigOps website.

## Runtime contract

There are no runtime changes from 0.4.0. The single-site and Multisite observation, Network Admin evidence, guarded undo, compatibility, privacy, and storage contracts remain unchanged.

## Release evidence

- Deterministic release archive and synchronized version metadata.
- Official WordPress Plugin Check and the complete ConfigOps test suite.
