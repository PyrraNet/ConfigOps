# ConfigOps 0.3.0

**Released:** 2026-08-16<br>
**Theme:** automatic evidence and undo

## Highlights

- Records supported Options API mutations automatically in isolated, request-local observations for authorized admin, REST, and WP-CLI requests.
- Shows immediate evidence with write, likely-decision, technical, and protected-secret counts plus direct Review and safe whole-save Undo actions.
- Keeps named Change Sessions for planned work that spans several requests.
- Stores automatic and named evidence as explicit modes and fails interrupted or incomplete observations closed.
- Carries bounded field-name and label intent into the same automatic save without reading configuration values or expanding undo authority.
- Introduces the “ConfigOps – Undo Settings Changes” directory identity and WordPress Change Intelligence positioning.

## Boundaries

This release remains a local, single-site Options API evidence and compensating-undo layer. It is not an activity log, backup, plugin-code rollback tool, fleet controller, or generic transaction engine for custom tables. Branded exports, Save Autopsies, the WordPress Change Index, a public demo, and AI-agent provenance remain later milestones.
